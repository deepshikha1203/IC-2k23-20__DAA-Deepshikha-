# Algorithm Performance Analyzer

## Objective

The objective of this project is to develop an Algorithm Performance
Analyzer that compares the theoretical and experimental complexity
of different algorithms.

## Algorithms

- Linear Search
- Binary Search
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Features

- Best-case analysis
- Average-case analysis
- Worst-case analysis
- Execution-time measurement
- Experimental result storage
- Performance graphs
- Theoretical vs experimental comparison

## Technologies

- Python
- Pandas
- Matplotlib
- Git
- GitHub
